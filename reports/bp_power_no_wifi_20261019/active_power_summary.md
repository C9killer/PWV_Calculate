# 血压计算有效宽峰功耗简析

根据用户确认，将宽峰作为血压模型计算的活动区间。Wi-Fi 关闭时，不计算的平均功率为 **510.66 mW**，有效宽峰内系统平均功率为 **570.70 mW**，计算期间平均增加 **60.04 mW（11.76%）**。

| 指标 | 结果 |
|---|---:|
| 不运行血压计算的平均功率 | 510.66 mW |
| 有效宽峰内时间加权平均功率 | 570.70 mW |
| 计算期间平均功率增量 | +60.04 mW |
| 相对不计算时的增幅 | +11.76% |
| 有效宽峰数量 | 19 个 |
| 有效宽峰累计时长 | 7.376 s |
| 单个宽峰平均跨度 | 388.2 ms |
| 单个宽峰跨度范围 | 346–406 ms |
| 各宽峰区间平均功率范围 | 568.39–571.64 mW |

## 简要分析

血压计算使系统功率由约 511 mW 上升到 571 mW，计算活动期间增加约 60 mW，增幅约 11.8%。各宽峰平均功率相近，说明本次有效计算区间的功率水平较一致。宽峰期间功率上升明显，而计算间隙会拉低整段录制的平均增量，因此此前全程约 13–15 mW 的增量与这里约 60 mW 的活动期增量并不矛盾。

上述约 571 mW 是计算期间整机在仪器测量点的总功率，约 60 mW 是相对无计算对照组的增量，包含特征处理、模型推理、血压后处理及相关附带开销。

## 统计口径

- 使用本次开启计算文件全部 40.118 s 中的 19 个有效宽峰；无计算基线使用对照文件全部 33.158 s。这里比较的是条件平均功率，不直接比较两份不等长记录的累计能量。
- 沿用此前宽峰提取规则：20 ms 移动平均高于 550 mW，合并不超过 50 ms 的间隙，保留跨度至少 100 ms 的区间。平滑仅用于定位；区间功率仍对原始记录积分，全部区间能量除以全部区间时长，得到时间加权平均。
- 此前约 571.1 mW 是各峰平均功率的中位数；本次使用所有有效宽峰合并后的时间加权平均，口径不同。
- 若仍只用前 30 s，则有 14 个有效宽峰：基线 510.72 mW，宽峰平均 570.63 mW，增量 59.92 mW（11.73%），与全文件结果一致。
- 宽峰数量代表所选计算活动区间数量，不能据此确定成功血压输出次数；跨度按功率波形定位，边界会受提取规则和仪器响应影响。
