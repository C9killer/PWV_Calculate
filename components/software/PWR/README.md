# AXP2101 电源调用层

调用关系：`app_main -> PWR -> AXP2101 -> IIC -> ESP-IDF I2C master`。
沿用项目结构，IIC、AXP2101 是 hardware 下的模块，PWR 是 software 下的模块，
由两个已有组件的 CMakeLists.txt 自动收集源文件。

## 本板配置

| 项目 | 配置 |
| --- | --- |
| I2C | SCL=GPIO4，SDA=GPIO5，7 位地址 0x34，100 kHz |
| PWRON | 内部上拉，按键接地，按下为低 |
| PWROK | 连接 ESP32 EN，由硬件控制，不作为普通 GPIO 操作 |
| DCDC1 | 3.3 V，ESP32 供电，初始化期间始终保持开启 |
| ALDO1 | 3.3 V，模拟电源 |
| ALDO2 | 1.6 V，参考电源；不支持直接配置 1.65 V |
| 开机 | 512 ms |
| 硬件关机 | 持续按住 6 s，动作选择关机而非重启 |

按照最终确认，不修改 IRQ 使能/状态寄存器，不连接或处理 IRQ，不创建按键轮询任务。
REG27 的长按事件阈值仍为 1.5 s，但没有软件处理，因此 **1.5 s 不会关机**。
芯片出厂可能已经使能部分 IRQ；“不配置”并不表示驱动会主动屏蔽出厂 IRQ。

## 使用与错误处理

通信诊断：启动时先探测 0x34，然后无论探测是否应答，都尝试在 100 kHz 下
直接读取 REG00。若读失败，执行一次 0x08～0x77 地址扫描，再以 10 kHz
直接读取 REG00；低速成功时，后续电源配置也保持 10 kHz。
ESP-IDF 6.1 的地址探测/扫描固定为 100 kHz，与设备读写频率独立。
扫描只打印应答地址，不自动改用其他地址。两次读取均失败时不配置任何电源寄存器。
`Communication established` 表示实际寄存器读取成功；注册设备句柄成功不表示通信成功。

`app_main()` 在 LED 和其他外设初始化前调用 `PWR_Init()`。
初始化失败时打印失败步骤和错误码，停止后续外设启动，不自动重启 PMIC。
如果中途失败，已成功的配置可能保留，不执行可能切断 ESP32 供电的回滚。

`PWR_PowerOff()` 供业务层主动关机使用；调用前完成数据保存和外设收尾。
该接口发送 REG10 bit0 软件关机命令，电源可能在 I2C 返回前消失。
若返回错误，需要由上层诊断；不要因超时就自动重启或反复发送命令。
6 s 硬件关机不等待软件保存数据。

接口仅用于任务上下文，初始化应在启动其他使用者之前完成。
与现有 LED 模块一样，由调用方串行使用；以后增加多个任务时，应在调用层加锁，
不要让其他任务绕过 PWR 同时修改 AXP2101 寄存器。

普通配置使用保留其他位的读改写，并校验目标位读回值。
电压接口严格校验范围及 100 mV 步进，不会把 1650 mV 静默取整。

## 硬件与默认配置边界

- DCDC1 必须在 ESP32 执行代码前就能按默认配置提供合适的供电；
  软件无法修复“ESP32 未上电而需要 ESP32 开启 DCDC1”的情况。
- 代码不烧写 EFUSE。完全断电后的首次开机时间、默认输出和启动顺序仍由芯片默认配置决定。
  输出电压/使能在系统复位时可恢复默认值，因此每次启动都执行初始化。
- SDA/SCL 需要上拉到 3.3 V 逻辑电源，手册要求外部 2.2 kΩ 上拉；
  ESP32 的弱内部上拉仅作辅助。PWRON 的内部上拉与 I2C 上拉不同。
- VBUS=5 V、VMID/VSYS/ALDOIN 的连接是硬件电源路径，不是 DCDC/LDO 电压设置。
  驱动不设置“VMID=5 V”，也不保证 VSYS 恒定为 5 V；路径存在压降，
  电池供电时 VSYS 还会随电池变化。确认 ALDOIN 和 VIN1 的实际供电及余量。
- 不修改充电参数、VBUS 输入限流、PWROK 时序或其他未指定输出。
- 依据本地 AXP2101 V1.4 手册：REG22 按第 36 页详细表设置 bit1=1、bit0=0；
  第 20 页文字中的重启选择位域与该表不一致，需在实板验证长按行为。

## 实板验证

重新配置并构建：`idf.py reconfigure build`。
烧录后检查初始化日志，并测量 DCDC1=3.3 V、ALDO1=3.3 V、ALDO2=1.6 V。
确认持续按 1.5 s 不关机、6 s 关机，再按约 512 ms 开机；完全断电后首按使用出厂时长。
检查 PWROK/EN 时序、再次启动，以及 VBUS 插拔时是否有出厂自动开机行为。
寄存器读回成功不能代替实际电压和电源时序测量。
